WHAT IT FIXES

きれいな文章ほど、ズレに気づきにくい。

最近のChatGPTやClaudeは素のままでも自然な日本語を書きます。ただ、仕事のメールや資料を任せると、頼んでいない約束が足されたり、自分が普段使わない硬い敬語が混ざったりします。

依頼 明日の打ち合わせを来週にずらしたいメールを書いて
素のAIの出力（実測・抜粋）

大変恐縮ですが、日程を来週へ変更させていただくことは可能でしょうか。上記以外にご都合のよいお時間帯がございましたら、そちらに合わせますのでお知らせください。

nihongoを入れた出力

急で申し訳ありません。明日の打ち合わせですが、【理由】のため来週へ変更いただけますか。【候補日時】でご都合はいかがでしょうか。

依頼に無い約束は足さず、分からない値だけ空欄にします。敬語も必要以上に高くしません。

CAPABILITIES

書く仕事はAI、守る仕事はコードへ分ける。

プロンプトに長いルールを詰め込むほど、AIは見落としやすくなります。文章を整える作業は軽いルールでAIに任せ、変えてはいけない事実や避ける表現はローカルのコードで止めます（下の自動検査と承認画面はPCの開発ツール向け機能で、ブラウザやスマホのチャットは下の導入ルールだけで使えます）。

編集後のズレを0トークンで検出する

原文とAIが直した文を比べ、数値・日時・否定・「必ず」の弱まり・自分で登録した避ける表現をPythonの標準ライブラリだけで検出します。Claude CodeのPostToolUseフックやgit差分チェックにも組み込めます。

$ nihongo-check diff orig.md draft.md --profile ~/.nihongo/profile.md --scene formal
- [確度・必須度] 「必須」表現が減少（1→0）
- [程度・約束] 「必ず」が減少（1→0）
- [程度・約束] 「頃」が増加（0→1）
- [個人ルール] 避ける表現を検出: 「いただけますと幸いです」
0 tokens / ローカル実行 / 追加パッケージ不要
このブラウザ内で0トークン検査を試す（データは外部へ送信されません）

会話で直した癖は承認して残す

普段のチャットで「この言い回しは使わない」と直した内容だけ、MCP経由で受信箱（inbox.jsonl）に一時保存されます。勝手に上書きせず、ローカルの承認画面（nihongo-check ui）でOKを押したものだけが自分の profile.md に反映されます。メールアドレスやAPIキーなどの個人情報は自動で拒否します。

複数PCでも案件別でも使い分ける

保存先はすべてユーザー本人の管理下に置きます。すでに nihongo を使っている場合も既存の profile.md を消さずに最新版へ更新できます。

  • 同じPCの複数AIへ nihongo-mcp init で一括設定
  • 自分のGoogle Drive等の同期フォルダで複数PC共有
  • 作業フォルダに .nihongo/profile.md を置けば分野別に重ねがけ
GET STARTED

今のチャットに1ファイルを貼るだけ。

ダウンロードしたメモファイル（nihongo-setup.md）を普段のAIチャットに添付するだけです。ChatGPTやClaudeのブラウザ・スマホ版ならその場からルールが効き、PCの開発ツール（Claude Code / Cursor / Antigravity等）なら安全確認と2回の承認を経て自動セットアップまで進みます。

スマホ・ブラウザで貼るだけの方：
開発者・すでに nihongo を使っている方向け
避ける表現を選ぶ 複数選択可・あとから会話でも追加できます
よく使う場面
PC開発ツール導入時の保存先（初期候補） ブラウザ・スマホだけで使う方はそのままでも使えます
生成される nihongo-setup.md の中身を確認する 

          

        


        

          

            
ブラウザ・スマホのチャット（ChatGPT / Claude / Gemini）の場合

            
いつものチャット画面で「＋（ファイル添付）」から選ぶか、上のボタンでコピーしたルールをそのまま送ってください。毎回貼りたくない場合は、ChatGPTのプロジェクト／カスタム指示、ClaudeのProjects、または自分のGoogle Driveに入れておくと便利です。

          

          

            
PCの開発ツール（Claude Code / Cursor / Antigravity等）の場合

            
AIが最初にGitHub正本の安全性（依存ゼロ・外部送信ゼロ）を確認し、「導入・更新してよいか」「保存先をローカルかGoogle Driveにするか」の2回の承認を求めます。OKを押すと既存設定を退避した上で自動設定が終わります。
