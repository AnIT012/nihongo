CAPABILITIES

仕上げと確認を4つの機能で引き受ける。

普段の返事から重要な資料・編集後の検査まで、場面に応じて自動で切り替わります。

Lite

普段の返事を軽く整える

約1,100〜1,260字の軽量ルール。雑談や短い連絡でも重くならず、ブラウザやスマホでもそのまま使えます。

Full

メール・資料・技術文書まで

93行の本編と21本の場面別資料。必要な資料だけを読み込み、敬語の段や構成まで場面に合わせます。

Check

0トークンで意味ズレ検出

編集後の日時・数字・「必ず」の弱まりと避ける表現をPython標準ライブラリだけで検出。Claude Codeフック対応。

Personal

会話で育つ4場面の個人ルール

直した癖は受信箱に一時保存し、チャットで確認してOKした分だけ反映。Google Drive共有や案件別2層に対応。

Check（0トークン検査）の実行例とブラウザ内お試しを開く
$ nihongo-check diff orig.md draft.md --scene formal
- [確度・必須度] 「必須」表現が減少（1→0）
- [程度・約束] 「頃」が増加（0→1）
- [個人ルール] 避ける表現を検出: 「いただけますと幸いです」
0 tokens / ローカル実行 / 追加パッケージ不要
