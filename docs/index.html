AIの出力への手直しを減らそう。

過剰な敬語や意味のズレを防ぎ、自分の書き方を残せる日本語ガード。

無料・登録不要 運営サーバー保存なし
01

nihongoとは

使うと日々の文章がこう変わります

nihongoは、ChatGPTやClaudeに読み込ませて使う「日本語のルールブック」です。
AIが書きがちな硬すぎる敬語や頼んでいない約束を止め、自分の書き方を残したまま文章を整えられます。
特別なアプリは要らず、ファイルを1つチャットに貼るだけで今日から使えます。

就活生・学生

ESの下書きや連絡メールを自分の言葉のまま整えます

書いた経験を盛らず、表現の硬さやクセだけを直します。

仕事・普段の連絡

メールやLINEを書き直さずそのまま送れます

高すぎる敬語や頼んでいない約束を止め、大事な日時や「必ず」の言い換えも防ぎます。

AIをよく使う人

毎回「もっと自然に」と頼み直さなくて済みます

会話で直した口調や苦手な言い回しを保存でき、ChatGPTでもClaudeでも同じ自分の書き方にそろえられます。

02

得意・不得意

用途ごとの対応目安
◎ メール・チャット・普段のやりとり 敬語の段や距離感、LINE・Slackの文体まで整えます
◎ ES・自己PR・UI文言・お知らせ 事実を盛らず場面ごとの型に合わせます
○ 記事・技術文書・企画書・議事録 構成の整理や推敲と、数字や約束のズレ検出に対応します
○ 告知文・LP・紹介文 AIっぽい抽象表現や根拠のない誇張を止めて整えます
△ 本格的な広告コピー・スライド作成 日本語や構成の補助まで。売れる企画設計やデザインは対象外です
× 事実の創作・なりすまし・詐欺 安全のため対応しません
03

よくあるAIのズレ

「きれいだけどそのまま出せない」主な原因
よくあるズレ 素のAIがやりがちなこと nihongoの対処
ニュアンスが弱まる 素のAI「明日15時までに必ず」が「15時頃までにいただけますと幸いです」にぼやける nihongo日時・数字・「必ず」の強さを変えず、ズレがあれば検出します
余計な約束が付く 素のAI「そちらに合わせます」「何でもお気軽に」など頼んでいない申し出を足す nihongo依頼にない約束や理由は足さず、分からない所だけ空欄にします
距離感に合わない 素のAI同僚へのチャットが取引先並みに硬くなったり、目上へ砕けすぎたりする nihongo相手と場面に合わせて敬語の高さをちょうどよく整えます
前置きとまとめが長い 素のAI相手の言葉を言い直してから本題に入り、最後に無難な感想を並べる nihongo余計な前置きと言い直しを省き、頼まれた中身だけを返します
AI定番の表現になる 素のAIESや紹介文が「革新的な」「大変有意義な」のようなテンプレ文に変わる nihongo書いた事実だけを自然な言葉に整え、嫌いな表現は個人ルールで止めます
04

4つの機能

普段の返事から大事な書類の確認まで
Lite 普段のチャット用

約1,100字で短い返事や雑談を整えます

重くならずに効くため、スマホのChatGPTやClaudeの通常チャットでもそのまま使えます。

スマホ・Web即対応 敬語1段下げ
Full メール・ES・資料用

22本の場面別手引きを必要な時だけ読み込みます

メール・就活ES・UI文言・技術文書・企画書・告知文まで、相手と媒体の型に合わせます。

22本の場面別手引き 必要な分だけ読込
Check 0トークン自動検査

日時・数字・「必ず」のズレを自動で検出します

Python標準ライブラリだけで動き、編集前後の意味ズレや避けたい表現を機械的に見つけます。

0トークン実行 Claude Codeフック対応
Personal 会話で育つ個人ルール

直した口調やNG表現を確認後に残せます

普段・仕事・公式など4つの場面で切り替わり、DropboxやGoogle Driveで複数端末に共有できます。

承認制で勝手に変わらない 4場面で自動切替
チェック機能をブラウザで試す ▾
$ nihongo-check diff orig.md draft.md --scene formal
- [確度・必須度] 「必須」表現が減少（1→0）
- [程度・約束] 「頃」が増加（0→1）
- [個人ルール] 避ける表現を検出: 「いただけますと幸いです」
0 tokens / ローカル実行 / 追加パッケージ不要
